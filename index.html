Featured Project

WorkeAfrica – AI-Powered Job Discovery Platform

WorkeAfrica is a cutting-edge job discovery and career management platform revolutionizing job hunting across Africa. The platform leverages AI-powered CV parsing and intelligent job matching algorithms to deliver personalized job recommendations directly to candidates. Built with enterprise-grade security featuring httpOnly cookie-based authentication, automatic token refresh, and comprehensive CSRF protection, the application provides a seamless user experience with real-time job search, advanced filtering capabilities, and an intelligent recommendation system. As part of the frontend development team, I actively implemented key features including the Next.js 16 frontend with App Router, sophisticated state management using Zustand and React Query, comprehensive dashboard components with profile management featuring AI-powered CV extraction, job search system with real-time filtering, saved jobs functionality, and tier-based recommendation engine.

Next.js 16 React 19 TypeScript Zustand React Query Tailwind CSS Radix UI OAuth 2.0 FastAPI
Featured Project

WorkeAfrica Backend – AI-Powered Job Matching Platform

A production-grade job matching platform that uses AI embeddings and semantic search to connect African job seekers with relevant opportunities across all industries. The system automates job scraping from LinkedIn and BrighterMonday, performs intelligent CV parsing, and delivers personalized recommendations through a three-tier subscription model (Free, Pay-per-use, Monthly) via Telegram, Email, and WhatsApp. Features include AI-generated professional documents (CVs and cover letters), real-time payment processing with paystack integration, natural language chatbot for job searches, and comprehensive admin analytics dashboards. Built with FastAPI and PostgreSQL with pgvector, deployed with full CI/CD pipelines to DigitalOcean infrastructure.

Python 3.11 FastAPI PostgreSQL pgvector Redis OpenAI SQLAlchemy Docker GitHub Actions Telegram Bot API Paystack API
Featured Project

GreenPulse – AI-Powered Climate Intelligence Platform

GreenPulse is an AI-powered climate intelligence platform built by a team of three during a 24-hour hackathon, where I was trusted to develop the entire backend system in under 12 hours. The backend leverages FastAPI and GPT-4o to analyze climate patterns from NASA POWER and Google Weather APIs, providing real-time risk detection, regulatory compliance checking, and decision-support for environmental impact assessments. Built with a sophisticated AI intelligence engine, the system delivers multi-modal insights through a RESTful API, web dashboard, and intelligent Telegram bot, helping organizations make climate-smart decisions while ensuring NEMA compliance.

Python FastAPI OpenRouter (GPT-4o) NASA POWER API PostgreSQL React TailwindCSS Telegram Bot API
